## Мини‑приложение: расписание по видам спорта

Упрощённая версия: **3 раздела** (волейбол мужской, волейбол женский, футбол мужской) и **только расписание игр**.

### Данные

Редактируй `data/content.json`:

- `sports`: виды спорта (id/название/иконка)
- `teamsBySport`: команды по виду спорта
- `scheduleBySport`: расписание игр по виду спорта

Логотипы положи в `assets/logos/` и укажи путь в поле `logo`.

### Запуск

Открой `index.html` или подними любой статический сервер.
